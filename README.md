# D'art
D’art - социальная сеть на бесконечной плоскости с  возможностью публикации любого вида контента с помощью готовых шаблонов, генерации шаблонов с помощью нейросети или написания своих шаблонов на HTML.


## Описание

Проект D’art представляет из себя инновационную социальную сеть, представляющую из себя бесконечную плоскость, по которой каждый пользователь может бесконечно перемещаться в любом направлении и выкладывать контент любого формата в виде блока (который является HTML кодом). Сделать он это может с помощью встроенного ИИ-помощника(написав промпт и получив HTML код, который он сможет отобразить как web-страницу на плоскости), написав свой личный HTML код или использовав готовый шаблон из библиотеки(Такие, как размещение фото или текста на плоскости). Благодаря использованию HTML, пользователь может стилизовать контент с помощью включенного в него CSS и добавлять интерактивные элементы с помощью JS.Также пользователю предоставляется возможность получить в индивидуальное пользование часть плоскости, разместив на ней свою “область”, в пределах которой редактировать контент сможет только он. 


В рамках разработки D’art мной была создана уникальная технология “бесконечной прокрутки” для React и React-Native c возможностью бесконечного листания плоскости в любую сторону, ее масштабирования относительно положения пальцев и размещения на ней контента. На данный момент не существует библиотек, дающих подобный функционал.


D’art - docker-compose проект, с несколькими контейнерами. Frontend написан на React, Backend на Go, для взаимодействий с Telegram-ботом и с ChatGPT по API используется Python. Для перенаправления запросов и использования защищенного соединения используется NGINX. Для аутентификации пользователя используются JWT-токены, а для связи между сервером и клиентом помимо https используется WebSocket-соединение для быстрой передачи данных.
